
### StockPulse AI

An AI-powered stock sentiment and price movement analysis platform. This project

- Analyzes the stock news sentiment
- Compares it with stock price movement
- Exposes the result through a web dashboard/API deployed using DevOps practices.

User enters a stock ticker like:

- NVDA
- AAPL
- TSLA
- MSFT

The app will:

- Fetch stock price data.
- Fetch or use sample financial news headlines.
- Analyze news sentiment using AI/NLP.
- Compare sentiment with price movement.
- Show results in a dashboard.
- Expose backend APIs.
- Run tests automatically.
- Build Docker image.
- Deploy to cloud.
- Add monitoring/logging.
